# Habgood Lab website

Static website for the Habgood Lab, Department of Life Sciences, University of Bath.

## Run locally

Open `index.html` in a browser, or use any simple local web server.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example `habgood-lab`).
2. Upload all files and the `images/` folder.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide the Pages address.

The site is deliberately plain HTML/CSS/JS so it can be edited directly in GitHub without a build system.

## Editing news

`news.html` is intentionally empty except for an explanatory placeholder. To add a story later, copy the structure of a `.publication` block or create a new article section in `news.html`.

## Main editable content

- `index.html` — homepage
- `research.html` — research themes and descriptions
- `people.html` — Rob's profile
- `publications.html` — selected publications
- `news.html` — news
- `join-us.html` — student enquiries
- `contact.html` — contact details
- `style.css` — visual design
- `images/rob-habgood.jpg` — profile photo
- `images/habgood-lab-logo.png` — lab logo
